Plugins for Map Extender

Extra plugins for the Map Extender browser extension — overlays, map tools and data layers. Add the registry below and they show up in the extension’s gallery, where you can read the source of any plugin before installing it.

Registry address
  1. In the extension popup, click Open Plugins.
  2. Click Browse gallery, paste the address, then Add registry.
  3. Open any plugin to read its code, then add it. Adding never enables it — you switch it on per site from the popup.
Plugins run with the extension’s access on the sites they match. Read the source before installing anything — the extension shows it to you first, and never updates plugin code without showing you what changed.
